# Web3 DAO Application

Ứng dụng phi tập trung Web3 (DAO Application) được xây dựng bằng React, Web3.js và Tailwind CSS.

## 🚀 Giới thiệu
Dự án Web3 DAO hỗ trợ kết nối ví điện tử (MetaMask), quản lý và bỏ phiếu các đề xuất (Proposals), cùng với khả năng tương tác với Smart Contract trên blockchain.

## 🛠 Công nghệ sử dụng
- **Frontend Framework**: React.js (v17)
- **Web3 Integration**: Web3.js
- **Styling**: Tailwind CSS
- **UI Components & Icons**: React Icons, React Identicons, Recharts, React Toastify

## ⚙️ Hướng dẫn cài đặt và chạy ứng dụng

1. **Cài đặt các thư viện cần thiết**:
   ```bash
   npm install
   ```

2. **Cấu hình môi trường**:
   Sao chép `.env.example` thành `.env` và điền các thông tin cần thiết:
   ```bash
   cp .env.example .env
   ```

3. **Chạy ứng dụng trong môi trường phát triển**:
   ```bash
   npm start
   ```
   Ứng dụng sẽ chạy tại địa chỉ `http://localhost:3000`.

## 📦 Build sản phẩm
```bash
npm run build
```
